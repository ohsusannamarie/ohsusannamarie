# 👋 Hey y’all, I’m Susanna

I build sourcing tools, talent intelligence dashboards, and recruiter infrastructure for people who are tired of doing everything manually.

Most of my work lives somewhere between sourcing strategy, market intelligence, workflow automation, and “this process is annoying, I should probably build something for it.”

I currently work in semiconductor and AI engineering talent, where the hiring problems are complex, the talent pools are weirdly specific, and spreadsheets multiply when left unattended.

A lot of what I build starts with the same thought:

> “There has to be a better way to do this.”

Usually there is. Sometimes I build it.

🏆 3X SourceCon Hackathon Champion  
🤓 Founder, Sourcers Who Code  
⭐️ Innovation Star Award Winner

## 🛠️ What I build

### Sourcing tools

Bookmarklets, browser utilities, scrapers, search workflows, and random recruiter side quests that make sourcing faster and less painful.

### Talent intelligence systems

Dashboards and lightweight infrastructure for:
- market mapping
- competitor tracking
- pipeline visibility
- talent research
- sourcing operations
- turning giant messy datasets into something people can actually use

### Resource libraries

Curated sourcing resources, recruiter references, search frameworks, and “I already solved this once so nobody else should have to” repositories.

Most projects are intentionally lightweight - usually HTML/JS, single-file, zero install, and built to work immediately.

Because honestly, if setup takes 14 steps, nobody’s using it.

I founded **Sourcers Who Code** because sourcing and building tools honestly feel like the same brain in different outfits.

You pattern-match.  
You experiment.
